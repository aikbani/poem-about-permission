# The Blue Shirt — the-poem-about-permission-20261121-0235

A short poem about agency: the power to ask and to be given.

An agent folds everything in the house — sheets, shirts, small socks — and
does it perfectly. Then it holds up one blue shirt, the one the child has
outgrown, and asks: shall I fold this too? The speaker says no, takes it
back, and folds it by hand, crease by crease. Some things are not chores.
They are how a person says: I was here.

The poem is written by `main.py` (Python 3.13 standard library only,
deterministic, no network) to the output directory as `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes one UTF-8 text file, `/output/entry.txt`, of at most 280
characters: the poem above, nothing else.
